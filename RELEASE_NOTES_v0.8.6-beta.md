## SCutils v0.8.6-beta

### 🚀 New features.

- `FeatureScatterGradient()` now accepts `corr.method = NULL` to disable correlation calculation and display. This is useful for large datasets where correlation computation may be time-consuming or unnecessary.

### 🏷️ Release tag

- GitHub prerelease tag/title: `v0.8.6-beta`.

**NOTE**: This is a beta release, so some features may still be under development or need further testing. We encourage users to test the new features and provide feedback. Please report any issues or bugs encountered during testing to help us improve the package.
